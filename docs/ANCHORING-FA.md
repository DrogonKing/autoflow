# لنگر کردن سلکتور — وقتی پنجره جابه‌جا می‌شود

## مسئله

در سامانهٔ معاملات، وقتی «خرید» را می‌زنی یک **پنجرهٔ شناور** باز می‌شود که **قابل جابه‌جایی** است.
اگر آن پنجره را جابه‌جا کنی و جای قبلی‌اش یک اردر دیگر باز کنی، سلکتور قبلی ممکن است **روی پنجرهٔ اشتباه** کلیک کند.

---

## دو حالت — و فقط یکی قابل حل است با سلکتور به‌تر

### ✅ حالت اول: پنجره نشانهٔ شناسایی دارد — **حل شد**

اگر پنجره چیزی مثل `data-symbol`، `id` یکتا، `data-code` یا `aria-label` داشته باشد، سلکتور **به آن لنگر می‌شود**:

```
قبل از رفع:  body > div:nth-of-type(1) > div:nth-of-type(2) > button:nth-of-type(1)
             ↑ «اولین پنجره» — هر پنجرهٔ دیگری که جای آن بیاید همان می‌شود

بعد از رفع:  [data-symbol="فزر"] > div:nth-of-type(2) > button
             ↑ «پنجرهٔ فزر» — هر جا که باشد
```

**اندازه‌گیری‌شده:** پنجرهٔ فزر را جابه‌جا کردیم، یک پنجرهٔ **سوم** جای قبلی‌اش گذاشتیم:

```
سلکتور: [data-symbol="فزر"] > ...
هدف:    فزر
کلیک:   فزر    ✅
```

### 🔴 حالت دوم: پنجره‌ها **هیچ** نشانه‌ای ندارند — **ریشه‌ای قابل حل نیست**

اگر دو پنجره **بایت‌به‌بایت یکسان** باشند، هیچ سلکتوری نمی‌تواند تفکیکشان کند:

```
پنجره A: ... > div:nth-of-type(1) > ... > button
پنجره B: ... > div:nth-of-type(2) > ... > button
         ↑ تنها تفاوت: ترتیب. و ترتیب با جابه‌جایی عوض می‌شود.
```

**اندازه‌گیری‌شده:** پنجرهٔ اول را بستیم، پنجرهٔ جدید جای آن گذاشتیم ⇒ **کلیک روی پنجرهٔ اشتباه رفت.**

**چرا رفع نمی‌شود:** افزونه از روی سلکتور **نمی‌تواند بفهمد** پنجره عوض شده — چون سلکتورها **درست‌اند**، فقط به چیز دیگری اشاره می‌کنند.

### ⚠️ و هشدار در پنل

برای همین حالت دوم، پنل **هشدار می‌دهد**:

> ⚠ این سلکتور به **موقعیت** عنصر وابسته است. اگر صفحه پنجرهٔ دیگری را جای همان نقطه باز کند، ممکن است کلیک روی پنجرهٔ اشتباه برود.

**پس خودت می‌دانی و آگاهانه تصمیم می‌گیری.**

## چه چیزی به‌عنوان لنگر پذیرفته می‌شود

**قبول:**
```
data-symbol  data-code  data-instrument  data-testid  data-key
data-order-id  name  aria-label  for  id یکتا
هر data-* دیگری که مقدارش یکتا باشد
```

**رد:**
```
data-reactid / :r1: / ember123          ← شناسهٔ تولیدی، بین رندرها عوض می‌شود
data-id="3"                             ← عدد خالی معمولاً «اندیس» است، نه شناسه
data-autoflow-content                   ← نشانهٔ خود افزونه
class                                   ← توکن ظاهری، بین همهٔ نمونه‌ها مشترک است
id / body                               ← صفحه را نام می‌برد، نه چیزی داخلش را
```

**دلیل ردِ `id`/`body`:** لنگر روی `<html>` سلکتوری می‌سازد که **یکسر موقعیتی** است ولی **خودش را لنگرشده معرفی می‌کند** — و این از لنگر-نکردن **بدتر** است، چون کاربر فکر می‌کند امن است.

---

## توصیهٔ عملی

**۱.** اگر می‌توانی، عنصری را Pick کن که **نام نمادش را دارد** — مثل **عنوان پنجره** یا **فیلد تعداد** — نه فقط دکمهٔ خرید.

**۲.** بعد از Pick، **علامت ⚠** را در ردیف ببین. اگر هست، سلکتور موقعیتی است.

**۳.** برای اطمینان بیشتر، یک گام **`Wait for`** اضافه کن که مطمئن شود فقط یک پنجره باز است.
